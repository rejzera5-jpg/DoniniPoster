Режим «В фоне» (программа сама, например Sbazar): 1) «Войти» — войдите в свой аккаунт в окне программы (один раз). 2) «Записать» — выставьте объявление как обычно, тексты вставляйте кнопками панели, фото — кнопкой сайта; перед «Опубликовать» нажмите на панели «Следующий клик = Опубликовать», потом «Готово». Тестовое объявление при этом не публикуется. 3) «Тест» — программа сама заполнит форму и остановится перед публикацией.
Режим «В моём браузере» (для всех сайтов, где нужен вход через Google или есть защита от ботов): поставьте расширение Donini (Настройки → «Расширение для браузера»). Дальше: значок Donini в браузере → «Записать» (один раз на сайт) → «Выставить».
Вид товара (линия) = своя папка в очереди + свой шаблон текста + свои сайты. Например «Сумки» — на 7 сайтов, «Кошельки» — на 4.
Чтобы добавить новый вид (обувь, ремни, шапки…): нажмите «+ Добавить вид товара», впишите название и папку, выберите шаблон текста и сайты, нажмите «Сохранить линии». Потом в окошке расширения Donini выберите этот товар и запишите сценарий для каждого его сайта.
Изменения сохраняются сами

🌐 Мой сайт (WooCommerce)

Товары из отдельной папки «Очередь сайта» (рядом с «Очередь») загружаются на сайт напрямую, без браузера — параллельно с выставлением на доски.
Ключ: WordPress → WooCommerce → Настройки → Дополнительно → REST API → «Добавить ключ» (права «Чтение/Запись»).
Пароль приложения: Пользователи → Профиль → «Пароли приложений» (для загрузки фото).
Каждый новый товар = копия образца: те же категория, цена, описание, атрибуты, доставка. Меняются только фото, артикул (код), бренд и размер — и в названии/описании тоже. Пусто — текст из шаблона Donini.
Без образца: название, описание и цена — польские, из шаблона линии «Мой сайт»; код товара → «Артикул» (SKU); бренд и размер из названия папки → атрибуты.

Если сайты открываются только через VPN: включите VPN-программу на компьютере (работает сразу для всех), или нажмите кнопку ниже и поставьте своё VPN-расширение в браузер программы — оно там запомнится.

Свои шаблоны из Donini Manager

В Donini нажмите «Скопировать мои шаблоны текста» и вставьте код сюда. В тексте своих шаблонов можно писать {size} — туда подставится размер.

Расширение для браузера

Работает в вашем Яндекс Браузере / Chrome, где вы уже вошли во все аккаунты.
1) Нажмите кнопку ниже — откроется папка extension.
2) В браузере откройте browser://extensions (в Chrome — chrome://extensions) и включите «Режим разработчика».
3) Нажмите «Загрузить распакованное расширение» и выберите эту папку extension.
4) Закрепите значок Donini на панели браузера.
