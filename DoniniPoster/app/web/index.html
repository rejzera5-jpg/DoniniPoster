🌐 Загрузка на doninisklep.com…

Кладите папки товаров в «Очередь сайта». Загрузка идёт в программе, без браузера и параллельно с досками. Каждый товар — копия товара-образца: меняются фото, код, бренд, размер и цена.

📥 Добавить товары на сайт

Очередь сайта

⚙️ Подключение и образец товара
Ключ: WordPress → WooCommerce → Настройки → Дополнительно → REST API → «Добавить ключ» (права «Чтение/Запись»). Пароль приложения: Пользователи → Профиль → «Пароли приложений» (для загрузки фото).

📥 Добавить товары для досок можно сразу 100 папок или одну общую папку со всеми товарами

⚙️ Как публиковать: режим, паузы, фон

Очередь для досок

🧹 Плохие фото (битые, недокачанные, замыленные, повторы):

🇨🇳 微商相册 — альбомы поставщиков

Откройте в браузере альбом поставщика один раз — он сам появится здесь со списком разделов. Дальше: выберите раздел и вид товара → «⬇ Скачать в очередь». Альбом откроется в фоновом окне Chrome, фото скачаются в очередь, окно закроется само. Товары без размера тоже скачиваются — в объявлении просто не будет строки с размером.

🛍 Каталог моего сайта → в очередь для досок

Нажмите на товар — он скачается в очередь (можно нажимать подряд). «✓ в очереди» — товар сейчас лежит в очереди.
⬇ Скачиваю…
Выберите шаблон — Manager откроет его. В скобках — какие виды товара по нему выставляются. Правки сразу сохраняются в программу и применяются ко всем товарам с этим шаблоном (кроме товаров со своим текстом ✏️).
Как записать сценарий сайта В моём браузере (расширение): выберите вид товара и сайт → «● Записать». Откроется сайт — выставьте объявление как обычно, расширение запомнит шаги. Ничего не публикуется.
В фоне (программа сама): «Войти» → один раз войдите в аккаунт; «Записать» → пройдите форму; «Тест» — программа сама заполнит и остановится перед публикацией.

● Записать сценарий (в моём браузере)

Что это Вид товара (линия) = своя папка в очереди + свой шаблон текста + свои сайты. Например «Сумки» — на 5 сайтов, «Кошельки» — на 4. Если добавить сайт в вид товара — товары из его папки, которые уже выставлены на других сайтах, пойдут и на новый сайт (без дублей на старых).
Изменения сохраняются сами

🧩 Как установить расширение Donini в браузер

Расширение заполняет объявления на досках (OLX, Vatera, Jófogás…) в вашем браузере, где вы уже вошли в аккаунты. Подходят: Яндекс, Chrome, Edge, Brave, Opera. Firefox — нет.
Папка расширения: …

Яндекс Браузер

  1. В адресной строке откройте browser://extensions
  2. Справа вверху включите «Режим разработчика»
  3. Нажмите «Загрузить распакованное расширение» и выберите папку extension (путь выше)
  4. Нажмите на значок пазла 🧩 справа от адресной строки и закрепите Donini Poster

Google Chrome / Brave / Opera

  1. Откройте chrome://extensions (в Opera — opera://extensions)
  2. Справа вверху включите «Режим разработчика»
  3. «Загрузить распакованное расширение» → папка extension
  4. Закрепите значок Donini Poster

Microsoft Edge

  1. Откройте edge://extensions
  2. Слева внизу включите «Режим разработчика»
  3. «Загрузить распакованное» → папка extension

Проверка

  1. Вверху окна программы должно гореть зелёным «расширение v…».
  2. Если красное: «Настройки» → «🌐 Браузер с расширением» — выберите свой браузер, потом «🔄 Перезапустить браузер».
  3. После обновления программы расширение обновляется при перезапуске браузера (или кнопкой ⟳ на странице расширений).

💾 Переустановка Windows / новый компьютер

  1. До переустановки: нажмите кнопку ниже — на рабочем столе появится «DoniniPoster резервная копия …zip» со всем: настройки, ключи сайта и Telegram, сценарии, шаблоны, очередь. Скопируйте его на флешку или Google Диск. Фото из очереди в архив не входят (они большие) — папку Очередь скопируйте отдельно, если нужно.
  2. После переустановки: поставьте свой браузер (Яндекс) и войдите в аккаунты сайтов.
  3. Распакуйте архив (правый клик → «Извлечь всё…»), например на рабочий стол.
  4. Запустите «Запуск.bat» — 3–5 минут программа ставит всё сама. Пути к папкам поправятся сами.
  5. Поставьте расширение из папки extension в браузер (инструкция слева) — и всё работает как раньше.

📦 Как передать программу другому человеку

  1. Нажмите кнопку ниже (или «Настройки» → «📦 Сделать копию»). На рабочем столе появится DoniniPoster для передачи.zip — без ваших ключей, Telegram, очереди и журнала, но со всеми записанными сценариями сайтов.
  2. Отправьте архив: Telegram, Google Диск, флешка.

💻 Установка у нового человека

  1. Скачать архив и распаковать: правый клик → «Извлечь всё…», например в C:\DoniniPoster. Не запускать прямо из архива.
  2. В папке запустить «Запуск.bat». Первый запуск 3–5 минут: программа сама поставит всё нужное (нужен интернет).
  3. Появится ярлык «Donini Poster» на рабочем столе; программа будет запускаться вместе с Windows.
  4. Установить расширение в свой браузер (слева).
  5. В этом браузере войти в свои аккаунты на досках (OLX и др.).
  6. Свой сайт: «Мой сайт» → «⚙️ Подключение» — свои ключи WooCommerce.
  7. Уведомления: «Настройки» → «Уведомления в Telegram».

🚀 Как работать каждый день

  1. Товары: перетащите папки на плитку на «Главной» или возьмите в «⬇ Скачать фото» — из 微商相册 или со своего сайта.
  2. Свой сайт: «▶ Загружать на сайт».
  3. Доски: «▶ Выставлять подряд» или «📦 Пачкой на один сайт».
  4. Ошибки видны красным в очереди: «Повторить» или «Пропустить».
