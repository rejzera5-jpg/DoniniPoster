DONINI POSTER — автоматическое выставление объявлений
=====================================================

УСТАНОВКА (один раз, 5 минут)
-----------------------------
1. Распакуйте архив в C:\DoniniPoster  (лучше путь без русских букв и пробелов).
2. Дважды кликните «Запуск.bat».
   Откроется синее окно установки: оно само скачает всё нужное.
   В конце спросит про автозапуск вместе с Windows — ответьте д или н.
3. Откроется окно программы в браузере. На рабочем столе появится ярлык «Donini Poster».

Программа работает В ФОНЕ. Окно в браузере можно закрыть — выставление продолжится.
Открыть окно снова — ярлык «Donini Poster». Выключить совсем — Настройки → «Выключить программу».


ПЕРВАЯ НАСТРОЙКА
----------------
1. Вкладка «Настройки»: впишите последний использованный код (дальше пойдёт +1),
   настройте Telegram (инструкция там же), нажмите «Сохранить».
2. Вкладка «Линии товара»: проверьте, на какие сайты идёт каждая линия.
3. Вкладка «Сайты» — для КАЖДОГО сайта:
   а) «Войти / открыть сайт» — войдите в свой аккаунт (программа запомнит вход).
      Потом нажмите вверху «Свернуть браузер».
   б) «● Записать» — откроется сайт с тёмной панелью справа внизу.
      Выставляйте объявление как обычно:
        • категорию, галочки, город — кликайте как всегда;
        • название / описание / цену / размер / код — кликните в поле сайта,
          потом на панели кнопку «Название» (или «Описание», «Цена»…);
        • фото — просто нажмите кнопку загрузки фото на сайте, программа подставит сама;
        • перед публикацией нажмите на панели «Следующий клик = Опубликовать»,
          потом кнопку публикации на сайте — она ЗАПОМНИТСЯ, НО НЕ НАЖМЁТСЯ;
        • нажмите на панели «Готово».
      Ничего не публикуется во время записи.
   в) «Тест» — программа сама заполнит форму и остановится перед публикацией.
      Проверьте, что всё на месте.
   Если для другой линии товара нужна другая категория — запишите отдельный
   сценарий для этой линии (выпадающий список на карточке сайта).
4. Нажмите вверху «▶ Старт».


КАЖДЫЙ ДЕНЬ
-----------
Скачайте каталог товара (папку с фото или ZIP) в папку линии:
    C:\DoniniPoster\Очередь\Сумки\
    C:\DoniniPoster\Очередь\Другое\
Через несколько секунд товар появится во вкладке «Очередь» с новым кодом.

В названии папки можно указать (необязательно):
    26x16          -> размер 26*16 cm
    21x14 26x16    -> размер 21*14\26*16 cm
    699zl          -> цена 699 зл
    #83300         -> свой код вместо автоматического
Например:  «сумка черная 26x16 699zl»
Если ничего не указано — берутся размер и цена по умолчанию из «Линии товара».
Размер и цену можно поправить прямо в таблице очереди.

Дальше всё само: код +1, тексты по шаблонам Donini на языке каждой страны,
цена в местной валюте, фото, публикация. Каждый сайт работает в своём темпе
(пауза между объявлениями настраивается на карточке сайта).
Выставленные товары переносятся в папку «Выставлено» и через N дней удаляются.

Капча: программа развернёт окно и пришлёт в Telegram «нужна капча».
Решите её — программа продолжит сама.


ДОБАВИТЬ НОВЫЙ САЙТ
-------------------
Вкладка «Сайты» → «+ Добавить сайт» → название, адрес, язык текстов →
«Войти» → «Записать» → «Тест». Всё, сайт работает. Код менять не нужно.
Новую страну/линию товара — вкладка «Линии товара» → «+ Добавить линию».
Свои шаблоны из Donini Manager — Настройки → «Свои шаблоны из Donini».


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
• Красная метка «!» в очереди — кликните по ней: будет текст ошибки и скриншот.
  Чаще всего сайт поменял форму — просто перезапишите сценарий этого сайта.
• Журнал всех действий — вкладка «Журнал» (и файл data\log.txt).
• Обновление программы: замените папку app на новую. Папку data не трогайте —
  там ваши настройки, сценарии и вход на сайты.



РАСШИРЕНИЕ DONINI — РАБОТАЕТ НА ВСЕХ САЙТАХ (версия 3.0)
-------------------------------------------------------
Многие сайты (OLX, Milanuncios) и вход через Google не пускают отдельный браузер программы.
Поэтому есть режим «В моём браузере»: заполняет расширение Donini в ВАШЕМ Яндекс Браузере / Chrome,
где вы уже вошли во все аккаунты. Публикацию нажимаете вы.

Установка (один раз):
1. Программа → Настройки → «Расширение для браузера» → «Открыть папку расширения».
2. В Яндекс Браузере откройте адрес  browser://extensions  (в Chrome — chrome://extensions).
3. Включите «Режим разработчика» (переключатель вверху справа).
4. «Загрузить распакованное расширение» → выберите папку  extension  внутри DoniniPoster.
5. Закрепите значок Donini на панели браузера.

Запись сценария (один раз на сайт):
1. Значок Donini → «Записать сценария сайта» → выберите сайт → «● Записать».
2. Выставляйте как обычно: категория, галочки — кликайте сами; название/описание/цену — кликните
   в поле и нажмите кнопку на тёмной панели; фото — кнопкой сайта (подставятся образцы).
3. Кнопку публикации нажмите — она запомнится, но НЕ нажмётся. Затем «Готово».

Каждый товар:
1. Значок Donini → видно следующий товар → «Выставить на отмеченные сайты».
2. Откроется окно с вкладками сайтов — формы заполнятся сами (текст, цена, фото).
3. На каждой вкладке проверьте и нажмите «Опубликовать» (подсвечено). Товар отметится в программе сам.
Если какой-то шаг не сработал — панель подскажет: сделайте его сами и нажмите «Пропустить шаг».

Программа Donini Poster при этом должна быть запущена.
Режим каждого сайта меняется на вкладке «Сайты» → «Как выставлять».
Проверьте во вкладке «Линии товара», что нужные сайты отмечены у ваших линий.
