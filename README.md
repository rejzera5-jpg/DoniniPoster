# DoniniPoster

Программа для выставления объявлений (OLX, Vatera, Jófogás, Njuškalo, Publi24…) и товаров на свой сайт.

**Скачать установщик:** [DoniniPoster_Setup.exe](https://github.com/rejzera5-jpg/DoniniPoster/raw/main/DoniniPoster_Setup.exe)

Запустите установщик, нажмите «Далее» — программа поставится и дальше обновляется сама (кнопка «Обновить» в программе).
